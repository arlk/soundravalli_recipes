# Soundravalli's Recipes

A clean, categorized, and searchable recipe book.

## Features
- **Categorized View:** Recipes are grouped into logical categories like Rice & Tiffin, Sweets, and Pickles.
- **Dynamic Search:** Find recipes by name (English/Tamil), category, or ingredients.
- **Responsive Design:** Works on desktops, tablets, and mobile phones.
- **Fast & Simple:** No backend required. Pure HTML/CSS/JS.

## Local Development

To run the project locally:
1.  **Open `index.html`** in your web browser.
2.  Alternatively, use a local server:
    ```bash
    python3 -m http.server 8000
    ```

## Deployment to GitHub Pages

1.  Create a new repository on GitHub.
2.  Upload the following files to the root:
    - `index.html`
    - `style.css`
    - `script.js`
    - `data.js`
    - `README.md`
3.  Go to **Settings** > **Pages** and enable deployment from the `main` branch.

## Project Structure
- `index.html`: The main page structure.
- `style.css`: Clean, typography-focused design with support for Tamil fonts.
- `script.js`: Interactive logic for filtering and modal display.
- `data.js`: The recipe data source.
